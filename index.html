PGADCA Course Details

Course Overview

The Post Graduate Advance Diploma in Computer Applications (PGADCA) is a comprehensive program designed for graduates aiming to build a strong foundation in advanced computer science, software development, and IT operations.

What You Will Learn

  • Advanced C & C++ Programming
  • Database Management (SQL)
  • Web Dev (HTML, CSS, JS, PHP)
  • Python Programming Fundamentals
  • Operating Systems & Networking
  • Real-world Capstone Project

Career Opportunities

Software Developer, Database Administrator, Web Designer, IT Support Specialist, System Analyst.

Course Facts

Duration 12 Months
Eligibility Graduation
Mode Offline / Online
Total Fee ₹15,000

ADCA Course Details

Course Overview

The Advance Diploma in Computer Applications (ADCA) is tailored for 10th/12th pass students looking to gain practical computer skills for immediate employment in office administration and basic IT roles.

What You Will Learn

  • Computer Fundamentals & OS
  • MS Office Suite (Word, Excel, PPT)
  • Basic Financial Accounting (Tally)
  • Desk Top Publishing (DTP)
  • Internet & Email Operations
  • English & Hindi Typing

Career Opportunities

Computer Operator, Data Entry Operator, Office Assistant, Basic Accountant, Receptionist.

Course Facts

Duration 12 Months
Eligibility 10th / 12th Pass
Mode Offline

Course Overview

A specialized short-term certification in Tally Prime & ERP 9. This course equips you with the necessary skills to handle computerized accounting, inventory, and taxation for any business entity.

What You Will Learn

  • Company Creation & Ledgers
  • Inventory Management
  • GST Computation & Returns
  • Payroll Processing
  • Data Backup & Security

Career Opportunities
